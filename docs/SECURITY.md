# Security Policy

This repository is a WordPress engineering and learning project. Do not submit production credentials, client data or vulnerability details through a public issue.

For a suspected security issue, contact the repository owner privately through the published Saddam Hossen email and include:

- affected component and version;
- reproduction steps;
- impact and preconditions;
- suggested mitigation if available.

The project uses capability checks, nonces, contextual escaping, prepared database operations, allowlists, safe remote requests and privacy-first defaults. These controls still require environment-specific staging verification before production use.
