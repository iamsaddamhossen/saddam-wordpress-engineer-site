Companion plugin for Saddam Hossen’s WordPress engineering site.

== Description ==

The plugin keeps portable behavior outside the visual theme. It provides:

* Custom post types for projects, case studies, services and recommended tools.
* Registered metadata and native editing fields.
* Versioned REST API routes with validation and permissions.
* A server-rendered Gutenberg block.
* Contact storage, privacy export/erase support and retention controls.
* WP-CLI commands, Site Health diagnostics and cache lifecycle hooks.
* Contextual metadata, JSON-LD and an experimental llms.txt overview.
* An optional guided or server-side AI assistant.
* Idempotent starter content for the engineering site.

== Installation ==

1. Upload and activate the plugin.
2. Open Saddam Engineer  Starter Content.
3. Run Import / Repair Site Content once.
4. Save permalinks.
5. Configure profile, SEO, contact and assistant settings.
