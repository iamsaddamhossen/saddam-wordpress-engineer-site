# Saddam Engineer WordPress Theme 1.0.0

Initial public release of Saddam Hossen’s recruiter-focused WordPress engineering site.

## Design goals

- Clear senior WordPress positioning without excessive “portfolio” language.
- Fewer, stronger homepage sections.
- Balanced desktop and mobile layouts.
- Production case studies separated from broader website delivery.
- Practical technical writing without placeholder image blocks.
- Native WordPress editing patterns for non-technical content owners.
- Accessible, dependency-free frontend behavior.

## Companion plugin

Use Saddam Engineer Core 1.0.0 for custom content models, registered fields, REST routes, the dynamic block, lead storage, privacy tools, WP-CLI, Site Health, SEO/schema foundations, starter content and the site assistant.

## Installation

1. Activate the companion plugin.
2. Activate this theme.
3. Run Saddam Engineer → Starter Content → Import / Repair Site Content.
4. Save Settings → Permalinks.
5. Configure Homepage, Profile, SEO, Email and Assistant settings.
6. Clear all caches and test desktop and mobile views.

## Client editing model

The theme includes block patterns for an editable hero, feature grid, content split and CTA band. Repeatable business records use custom post types and registered fields in the companion plugin.
